#               Ollama is a separate binary, not a pip package)

# and the Postgres drivers used by the Docker stack + Alembic migrations. The
# final resolved set is identical to the pre-M11 single-file requirements.
#
# Python 3.12+ supported; 3.13 needs wheels for pydantic-core / asyncpg.
