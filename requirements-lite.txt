# requirements-lite.txt
# ======================
# M11 Lite profile — the Docker-free, low-spec install.
#
#   pip install -r requirements-lite.txt
#
# This is the shared base for every profile. It runs the full trading engine,
# all broker connectors, the dashboard and backtests on **SQLite** (set
# DB_BACKEND=sqlite) with no Docker, Postgres, Redis, or heavy AI stack.
#
# AI under Lite is the deterministic rules layer only — FinBERT sentiment and
# local reasoning models are NOT installed (see requirements.txt for Standard,
# which layers them on top of this file). The code degrades gracefully when
# torch/transformers are absent (ai/providers/fin_sentiment_provider.py).
#
# Python 3.12+ supported; 3.13 needs wheels for pydantic-core.
