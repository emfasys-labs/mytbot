myTbot is research and educational software provided for simulation, technical experimentation and operator-controlled use.

myTbot is not investment advice, financial advice, portfolio management, brokerage, custody, a managed trading service, a signal-selling service or a promise of performance. It does not provide personalised recommendations and does not manage money for users.

Trading financial instruments involves risk. Automated systems can fail, behave unexpectedly, execute unintended orders or lose money. No software can eliminate market, liquidity, execution, operational, model or infrastructure risk.

Users are solely responsible for:

- their own broker accounts
- API keys and account permissions
- risk settings and configuration
- data sources
- infrastructure and monitoring
- paper-mode testing
- any decision to enable live execution
- any orders placed through connected brokers

Broker API keys should never include withdrawal permissions. Use the minimum permissions required, normally read access and trade access only where needed.

Paper mode should be used before any live mode. Live execution, where enabled, is the operator's own responsibility.
